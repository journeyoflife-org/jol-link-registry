# Contributing to jol-link-registry

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes with clear commit messages.
4. Submit a pull request using the PR template.

## Code Standards

- Follow PEP 8 for Python code.
- All commits must be GPG-signed (`git commit -S`).
- No PII may appear in code, tests, or commits.

## Pull Request Process

1. Ensure all tests pass locally.
2. Update documentation if applicable.
3. Request review from a code owner.

## Reporting Issues

Use the GitHub issue templates for bug reports, feature requests, or broken links.
