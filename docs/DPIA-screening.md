# DPIA Screening (Data Protection Impact Assessment)

## Screening Checklist

| #  | Question                                                        | Answer |
| -- | --------------------------------------------------------------- | ------ |
| 1  | Does the system process personal data?                          | No     |
| 2  | Does the system process sensitive personal data (Art. 9)?       | No     |
| 3  | Is data transferred outside the EU/EEA?                         | No     |
| 4  | Is automated decision-making or profiling involved?             | No     |
| 5  | Is there systematic monitoring of publicly accessible areas?    | No     |
| 6  | Does the system process data on a large scale?                  | No     |
| 7  | Is data matched or combined from multiple sources?              | No     |
| 8  | Does the system process data concerning vulnerable subjects?    | No     |

## Conclusion

A full DPIA is **not required** for the JOL Link Registry as it does not process personal data. The zero-PII policy and automated scanners ensure this remains the case throughout the project lifecycle.

## Review Schedule

This screening shall be reviewed at every major release and whenever processing activities change.
